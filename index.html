معرفی دو زبان

جاوا اسکریپت چیست؟ جاوا چیست؟

JavaScript چیست؟

JavaScript
  • زبانی تفسیری و پویا برای وب و فراتر از آن
  • در سال ۱۹۹۵ توسط برندن آیک در نت‌اسکیپ متولد شد
  • قلب تعاملات صفحات وب در مرورگر
  • امروزه با Node.js در سمت سرور هم اجرا می‌شود
  • تک‌رشته‌ای، مبتنی بر رویداد و حلقه‌ی رویداد
نکته: نامش شبیه جاوا است، اما از نظر طراحی و فلسفه کاملاً متفاوت‌اند؛ این نام‌گذاری بیشتر جنبه‌ی بازاریابی داشت.

Java چیست؟

Java
  • زبانی کامپایل‌شده، ایستا و شیءگرا
  • در سال ۱۹۹۵ توسط جیمز گاسلینگ در سان مایکروسیستمز
  • شعار معروف: یک بار بنویس، همه‌جا اجرا کن
  • اجرا بر روی ماشین مجازی جاوا (JVM)
  • محبوب در سیستم‌های سازمانی، اندروید و بک‌اند
نکته: جاوا و جاوا اسکریپت دو زبان مستقل هستند؛ اشتراک نام فقط یک تصمیم تاریخی است.

// تعریف متغیر با let و const
let name = "JS";
const version = 2024;

// تابع ساده

}

اصول اولیه در Java

Main.java 
// کلاس و متد main
public class Main {

  public static void main(String[] args) {

    String name = "Java";
    int version = 2024;

    System.out.println("Hello " + name);
  }
}

// تعریف مجموعه
List<Integer> list = List.of(1, 2, 3);
ویژگی: نحو صریح و ساختارمند همراه با تعریف نوع داده‌ها.

SECTION 07

بسته‌بندی و کپسوله‌سازی

پنهان‌سازی و محافظت از داده‌ها

کپسوله‌سازی در JavaScript

counter.js 
// کپسوله‌سازی با Closure
function createCounter() {
  let count = 0;

  return {
    increment: () => ++count,
    get: () => count
  };
}

const counter = createCounter();

counter.increment();
console.log(counter.get()); // 1
ویژگی: کپسوله‌سازی با بستار (Closure) یا فیلدهای خصوصی (#) در کلاس‌ها.

کپسوله‌سازی در Java

Counter.java 
// کپسوله‌سازی با getter و setter
public class Counter {

  private int count = 0;

  public void increment() {
    count++;
  }

  public int getCount() {
    return count;
  }
}
ویژگی: کپسوله‌سازی با اصلاح‌گرهایی مانند private، protected و public.

کنترل ترتیب اجرای دستورات

جریان اجرا، شرط‌ها و حلقه‌ها

کنترل ترتیب اجرا در JavaScript

جریان کنترل
  • شرط if / else، انتخاب switch و خطایابی try/catch
  • حلقه‌های for، while و do...while
  • for...of و for...in برای پیمایش
  • Async / Await برای کنترل اجرای غیرهمزمان
  • Promise و حلقه‌ی رویداد ترتیب اجرا را مدیریت می‌کنند
ویژگی: اجرای غیرهمزمان و رویدادمحور، هسته‌ی رفتار جاوا اسکریپت است.

کنترل ترتیب اجرا در Java

جریان کنترل
  • شرط if / else، انتخاب switch و خطایابی try/catch/finally
  • حلقه‌های for، while و do...while
  • for-each برای پیمایش مجموعه‌ها
  • اجرای دستورات به‌صورت همزمان در حالت معمول
  • برای همزمانی از نخ و اجراکننده استفاده می‌شود
ویژگی: اجرای معمولاً خطی و همزمان؛ همزمانی با مدل مبتنی بر نخ.
