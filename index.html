نحو، ساختار و پایه‌ها

اصول اولیه در جاوا اسکریپت

example.js
// تعریف متغیر با let و const
let name = "JS";
const version = 2024;
 
// تابع ساده
function greet() {
  return `Hello ${name}`;
}
 
// شیء و آرایه
const user = { name: "Ali", age: 22 };
const list = [1, 2, 3];
 
// چاپ در کنسول
console.log(greet());
ویژگی: نحو سبک و انعطاف‌پذیر، بدون نیاز به تعریف نوع.

اصول اولیه در جاوا

Main.java
// کلاس و متد main
public class Main {
  public static void main(String[] args) {
    String name = "Java";
    int version = 2024;
    System.out.println("Hello " + name);
  }
}
 
// تعریف صریح نوع در همه‌جا
List<Integer> list = List.of(1, 2, 3);
ویژگی: نحو صریح، ساختارمند و نیازمند تعریف نوع.

بسته‌بندی (کپسوله‌سازی)

پنهان‌سازی و کپسوله‌سازی داده

بسته‌بندی در جاوا اسکریپت

counter.js
// کپسوله‌سازی با بستار (Closure)
function createCounter() {
  let count = 0;
  return {
    increment: () => ++count,
    get: () => count
  };
}
 
const counter = createCounter();
counter.increment();
console.log(counter.get()); // 1
ویژگی: کپسوله‌سازی با بستار یا فیلدهای خصوصی (#) در کلاس‌ها.

بسته‌بندی در جاوا

Counter.java
// کپسوله‌سازی با getter و setter
public class Counter {
  private int count = 0;
 
  public void increment() {
    count++;
  }
 
  public int getCount() {
    return count;
  }
}
ویژگی: کپسوله‌سازی با اصلاح‌گرهایی مانند private، protected، public.
